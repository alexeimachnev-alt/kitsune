## Запуск на Render
1. Залейте `index.html`, `bot.py` и `requirements.txt` в репозиторий GitHub.
2. Создайте **Web Service** на Render (`Build Command: pip install -r requirements.txt`, `Start Command: python bot.py`).
3. Добавьте переменные окружения `BOT_TOKEN` и `ADMIN_CHAT_ID` и запустите деплой.
