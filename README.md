# Kitsune — Telegram Mini App для заказа суши и пиццы (с фотографиями блюд)

Готовый комплект для запуска собственного приложения доставки в Telegram.

## Состав архива
- `index.html` — витрина меню с подгруженными фотографиями блюд, акций и логотипом ресторана Kitsune, корзиной, списанием 500 баллов и отправкой заказа в Telegram.
- `bot.py` — Telegram-бот на `aiogram 3`, который открывает витрину по кнопке, принимает заказы из Mini App и отправляет чек клиенту и администратору/на кухню.
- `requirements.txt` — зависимости для запуска бота.

---

## Пошаговая инструкция по запуску

### Шаг 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте команду `/newbot`.
2. Укажите название (например, `Kitsune Доставка`) и username бота (например, `kitsune_delivery_bot`).
3. Скопируйте полученный **API Token**.

### Шаг 2. Размещение витрины (`index.html`) по HTTPS
Telegram Mini Apps работают только по защищённому протоколу **HTTPS**. Вы можете разместить `index.html` бесплатно за 2 минуты любым из способов:
- **GitHub Pages**: создайте публичный репозиторий, загрузите туда `index.html`, включите `Settings -> Pages -> Deploy from a branch (main)` и получите ссылку вида `https://ваш-логин.github.io/репозиторий/`.
- **Vercel / Netlify / Cloudflare Pages**: перетащите папку с `index.html` в панель управления и сразу получите готовую HTTPS-ссылку.
- **Свой VPS / Nginx**: положите `index.html` в директорию сайта с настроенным SSL-сертификатом Let's Encrypt.

### Шаг 3. Настройка и запуск бота (`bot.py`)
1. Узнайте свой Telegram ID (или ID рабочего чата менеджеров) через бота [@userinfobot](https://t.me/userinfobot).
2. Откройте `bot.py` и укажите свои значения в переменных (или задайте через переменные окружения):
   - `BOT_TOKEN` — токен от `@BotFather`
   - `WEBAPP_URL` — ваша HTTPS-ссылка на `index.html`
   - `ADMIN_CHAT_ID` — ваш Telegram ID для получения новых заказов
3. Установите зависимости и запустите бота:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

### Шаг 4. Как добавлять свои фотографии для остальных позиций
В `index.html` в массиве `PRODUCTS` для всех основных сетов и пицц уже прописаны прямые ссылки на реальные фото (`image: 'https://...'`). Для остальных позиций предусмотрен автоматический резервный режим (если `image: ''` или фото недоступно, отображается аккуратная иконка). Чтобы добавить своё фото к любому блюду, просто вставьте прямую ссылку на картинку в поле `image`.
